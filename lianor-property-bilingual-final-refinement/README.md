# Lianor bilingual property-first site

Complete static website for GitHub Pages. Upload the contents of this folder to the repository root and preserve the existing `CNAME` file. See `REDESIGN-NOTES.md` for the complete sitemap and rationale.


## August 2026 refinements

- English copy normalized to US English.
- Homepage shortened to the primary property proposition, service cards, method, reporting, About Lianor and contact.
- Minimal copyright-only footer.
- Transparent PNG favicons rendered from the existing `nobg` logo, with a transparent multi-size `.ico` fallback and cache-busted references on every page.
- EN/IT dropdown showing the current language. On desktop it sits immediately to the right of the email; on narrow screens it moves into the mobile menu.
- Static homepage service summaries, with the full service pages available from the header dropdown.
- Renovation positioning refined around dedicated attention, consistent reporting and a trusted local network.
- A clearly visible About Lianor section now appears on both homepages.
- The Other Projects page has been rebuilt from the strongest original copy and is discreetly linked from the ongoing-coordination page, not the main header.


## Optional fixed homepage watermark

The fixed watermark style is already included but disabled. To test it, add `sticky-watermark` to the `<body>` class in `index.html` and `it/index.html`. Remove the class to return to the normal scrolling behavior.
